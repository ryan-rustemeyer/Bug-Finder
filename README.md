# 🐛 Bug Finder 🐛

Bug Finder is a web application that helps users discover insects in their area. Users enter a postal or ZIP code and select a country to explore local insect observations.

**[View the live demo](https://bug-finder-blush.vercel.app/)**

## Features

- Search for insects using a ZIP or postal code
- Support for multiple countries
- Display insect names and photographs
- Display summaries for each insect
- Click insect name to go to Wikipedia article
- Refresh results to discover more insects


## Technologies Used

- HTML
- CSS
- JavaScript
- [Zippopotam.us API](https://api.zippopotam.us/)
- [iNaturalist API](https://api.inaturalist.org/v1/docs/)
- [Wikipedia REST API](https://en.wikipedia.org/api/rest_v1/)

## How to Run

1. Clone or download this repository
2. Open the project folder in VS Code
3. Open `index.html` in your browser, or use the VS Code Live Server extension
4. Select a country, enter a ZIP or postal code, and search for insects
